# egel22.ru: ЕГЭ по информатике

Сайт с официальными заданиями ЕГЭ по информатике. Отдельный проект, с Telegram-ботом (репозиторий EGE) общие только дизайн и база заданий.

- Без входа и без сервера: обычные файлы на хостинге.
- Ответ проверяется в браузере по хэшу, самих ответов на сайте нет.
- Решённое хранится в памяти браузера (localStorage). Сайт не собирает персональные данные и не ставит cookie.
- На компьютере: главная в две колонки, в номере страницы по 10 задач, у каждой условие слева и поле ответа справа. На телефоне, как в боте, по одной задаче.

## Папки

```
egel22/
  src/        интерфейс: index.html, app.js, app.css, local.js (проверка и прогресс), шрифты, значки
  tools/      bank.py: читает базу ege-bank и раскладывает задачи по номерам
  build.py    сборка сайта (build.bat для Windows)
  site/       готовый сайт, его и публикует Timeweb
```

## Обновить сайт

1. Если база заданий обновилась, сначала перезапустите сборщик в `EGE/ege-bank`.
2. Двойной щелчок по `build.bat`. Он берёт задания из `..\EGE\ege-bank\data` и пересобирает папку `site`. Другую папку с базой можно указать так: `python build.py путь\к\data`.
3. GitHub Desktop: Commit и Push. Timeweb обновит сайт сам.

Поменяли дизайн в боте и хотите так же на сайте: перенесите изменения в `src/app.css` и запустите `build.bat`. Номер версии в адресах файлов ставится сам, браузеры подхватят новое.

## Первая публикация

1. GitHub Desktop: File, Add local repository, папка `egel22`. Он предложит создать репозиторий: Create repository, затем Publish repository.
2. Timeweb Cloud: App Platform, Создать, Frontend, тип **HTML/CSS/JS**.
3. Репозиторий egel22, ветка main, директория проекта `site`, команду сборки оставить пустой.
4. В настройках приложения привязать домен egel22.ru.

Размер сайта около 300 МБ, в основном картинки и файлы к задачам (лимит App Platform 2 ГБ).
